Expense Tracker

- A responsive web application built using HTML, CSS and JavaScript.

Features

- Income / Expense Tracker
- Add income and expense transactions
- Edit transactions
- Delete transactions
- View incomes
- View expenses
- view balance
- Filter by type
- Filter by category
- Use browser Local Storage to save data persistently
- Mobile responsive
- Monthly summary of expenses
- Visualization by category
- Form validation with error messages

Technologies Used

- HTML5
- CSS3
- JavaScript

How to Run

1. Clone or download the repo.
2. Open the project folder.
3. Open index.html, in a web browser.
No backend or additional installation is required.

Data Storage

Transaction data will be stored in browsers Local Storage. Hence, the transactions are persistent even after page refresh.
